# EJERCICIO 1 
Sistema Académico de Documentos
Descripción

En este proyecto se desarrolló un sistema académico en Java utilizando una interfaz llamada Imprimible.

Se crearon las clases:

Certificado
ActaNotas
HorarioAcademico

Cada clase implementa el método imprimir() mostrando un mensaje diferente.

También se utilizó:

Interfaces
@Override
Clases y objetos
Atributos propios en cada clase

Finalmente, se creó la clase Main para ejecutar el programa y probar el funcionamiento del sistema.
# Ejercicio 2
Sistema Bancario de Pagos
Descripción
En este proyecto se desarrolló un sistema bancario en Java utilizando una interfaz llamada Pagable.
Se crearon las clases:
-PagoEfectivo
-PagoTarjeta
-Transferencia
Cada clase implementa el método procesarPago() mostrando mensajes diferentes según el tipo de pago.
También se aplicó:
Interfaces
@Override
Validación de montos
Clases y objetos
Comisión para tarjeta y transferencia
Finalmente, se creó la clase Main para ejecutar y probar el sistema.
